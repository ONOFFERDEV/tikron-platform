# Ironsight asset provenance

Application code follows the repository's existing license. This file records
the game assets; it does not relicense any purchased pack.

- `client/relay-environment.ts`: original procedural architecture, ground texture,
  sign atlas and antenna geometry authored for Ironsight.
- `public/assets/relay-vista.webp`: flattened in-game promotional screenshot,
  generated by `scripts/inspect-map.mjs --write-vista`. Contains original Ironsight
  architecture and the licensed Synty skyline as part of the completed game scene.
  This is not a source model or reusable asset-pack export.
- All five `public/assets/**/*.glb` files: private, unversioned purchased Synty
  derivatives (operator animations additionally derive from purchased Quaternius
  UAL). Their source licenses govern use. See `public/assets/README.md`.
- No new CC0, AI-generated, third-party font, or audio assets were added in session 1.
- No new npm dependencies were added. Existing Three.js is MIT licensed; its
  dependency license information remains in the installed package.
